# Texture packs

Texture packs replace the game's textures with new ones, usually higher-resolution. The port supports the same packs
as Dusklight on PC, including HD packs such as **Dusklight HD by Storm**.

## Installing a pack

There are two kinds:

- **Packs from the mod browser**, or packed as a `.dusk` mod. Install them like any other mod (see [Mods](mods.md)).
  They switch on and off with the mod.
- **Loose texture folders**, in Dolphin's naming scheme (`tex1_…` files). Copy them into
  `sdmc:/switch/dusklight/texture_replacements/`.

Then turn on **Settings → Graphics → Enable Texture Replacements**.

## Memory on the Switch

The Switch has much less memory than a PC:

- Packs that ship compressed `.dds` textures load faster and use less memory than packs made of large `.png` files.
- A very large pack can make loading screens longer.
- If the game becomes unstable with a pack, try a lighter version of it, or the pack without its largest textures.

Texture packs belong to their authors. Download them from the place their authors publish them.
