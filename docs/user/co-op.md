# Co-op

Online co-op comes from **Crests of Courage** by remi, a mod in the Twilit Realm catalog. It is someone else's mod, not part of this
port. What the port provides is the networking it needs on the Switch, so the mod runs here the same way it runs on
PC, including sessions between a Switch and a PC.

## Setting it up

1. Install **Crests of Courage** from the in-game mod browser (see [Mods](mods.md)).
2. Restart the game when asked.
3. Follow the mod's own instructions to host or join a session.

The Switch must be connected to the internet.

## Things to know

- Network activity in the background, such as the mod browser, image downloads or update checks, can cause short
  hitches during a session. Avoid browsing mods while you play together.
- If the connection drops after the console went to sleep, restart the game.
- Co-op problems that also happen on PC belong to the mod's author. Problems only on the Switch belong here: open an
  issue with your log from `sdmc:/switch/dusklight/cache/logs/`.
